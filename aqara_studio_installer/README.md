# Aqara Studio Integration Installer (Beta)

A manual, one-shot Home Assistant App that places the native Aqara Studio custom integration into Home Assistant's custom_components folder. It is an installer, not a separate sensor service.

**Install > Start once > read Logs > restart Home Assistant Core > Add Aqara Studio integration.**

For all options, upgrade safeguards, and migration precautions, see the Documentation tab. This App needs write access to Home Assistant configuration to copy integration files. Existing REST and Matter entities are not changed.
